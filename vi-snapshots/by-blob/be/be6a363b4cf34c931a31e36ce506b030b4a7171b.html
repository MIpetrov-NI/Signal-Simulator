Sine Generator.lvlib:Shutdown Sine Generator.vi

Shutdown stage. Finalises a generation run when the client cancels or an error stops the acquisition loop and reports the number of samples elapsed. The simulator holds no hardware sessions, files or other resources, so nothing needs to be closed; this is the single place to release resources if the engine ever acquires any.
