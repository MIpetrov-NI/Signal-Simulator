Sine Generator.lvlib:Generate Sine Block.vi

Signal generation engine. Computes one block of a sine wave: signal[i] = amplitude * sin(2*pi*frequency*(start sample + i)/sample rate) and time[i] = i/sample rate in seconds, so every block starts at t = 0 on the time axis while the phase continues from the start sample. Amplitude is the peak value, frequency is in Hz and sample rate in S/s.
