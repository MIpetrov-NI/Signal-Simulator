Signal Generator.lvlib:Generate Signal Block.vi

Signal generation engine. Computes one contiguous block of a synthetic waveform (sine, square or linear chirp) with additive uniform noise, starting at an absolute sample index so consecutive blocks join without a phase discontinuity. Amplitude is the peak value, frequency is in Hz, sample rate in S/s and noise level is the RMS noise amplitude. A chirp sweeps from frequency up to min(10 x frequency, 0.45 x sample rate) in one second and repeats.
