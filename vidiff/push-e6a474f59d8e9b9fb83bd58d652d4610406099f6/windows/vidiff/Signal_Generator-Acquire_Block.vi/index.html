Signal Generator.lvlib:Acquire Block.vi

Acquisition stage. Produces the next block of synthetic waveform data as an XY pair (time in seconds, signal value) by calling the signal generation engine, and returns the absolute sample index at which the following block must start. No hardware is accessed.
