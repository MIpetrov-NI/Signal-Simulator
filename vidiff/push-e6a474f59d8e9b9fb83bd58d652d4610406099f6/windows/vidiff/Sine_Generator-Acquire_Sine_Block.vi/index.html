Sine Generator.lvlib:Acquire Sine Block.vi

Acquisition stage. Produces the next block of the sine wave as an XY pair (time in seconds from 0, signal value) by calling the signal generation engine, and returns the sample index at which the next block starts: the start advances by sample rate x update interval, so consecutive updates scroll the signal at real-time speed.
